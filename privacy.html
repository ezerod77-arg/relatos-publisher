Relatos Publisher — Privacy Policy

Last updated: October 30, 2026.

Operator and scope

Relatos Publisher is operated by Ezequiel Rodriguez for authorized content publishing and reporting. Contact: ezerod77ia@gmail.com. This policy covers the local application and this informational website, including its use of YouTube API Services.

Information accessed and purposes

After explicit Google OAuth authorization, the application processes channel and video identifiers, titles, descriptions, playlist information, publishing status and aggregate channel/video statistics such as views, subscribers, likes and comment counts. It processes selected media files and publishing metadata to upload and manage content, verify deliveries, prevent duplicate uploads and generate operational reports.

Google access and refresh tokens are stored in the operator’s local credential directory, separately from the public website source. The application does not ask for or store Google account passwords. Google authenticates the account and grants the requested permissions. Permissions include youtube.upload, youtube and youtube.force-ssl.

Other connected social platforms may provide account identifiers, basic profile information, upload permissions and publishing status. The TikTok integration sends selected files to the authorized creator’s inbox for review, rather than automatically publishing them through Direct Post.

Storage, access and sharing

Authorized API data, publishing inventory and reports are stored on the operator’s systems. Tokens are not published in this website or its public Git repository. Data is used for the authorized publishing and reporting functions, not sold or used for advertising profiles. Selected media and metadata are sent to the destination social platform to carry out the requested operation. Technical service providers may process data as necessary to provide hosting or authorized operational support.

This static website contains no application login, upload form, analytics script or advertising tracker. GitHub Pages hosts the website and may process connection information under the GitHub Privacy Statement. The website does not receive the desktop application’s OAuth tokens.

Retention and deletion

Authentication tokens are retained while needed for authorized access. Publishing records and API reports are retained for operational reporting and reconciliation; applicable YouTube API data must be refreshed or deleted within the periods required by YouTube policies. The operator handles deletion requests manually; this website does not provide an automatic deletion control.

To request deletion of locally stored tokens and associated Google/YouTube API data, email the operator and identify the affected channel. Do not send passwords or tokens. After verifying the request, the operator will delete the affected data within 30 days, including retained copies under the operator’s control as applicable. Data is also removed when authorization can no longer be verified, within the applicable policy period. Deleting local data does not delete videos already published on a social platform; those can be managed directly on that platform.

Revoke access

You can revoke Google access at any time through Google account security permissions. Revocation stops future authorized API access; contact the operator to request deletion of retained application data as well. Other platform connections can be revoked in the relevant platform’s account settings.

Google and YouTube policies

Relatos Publisher uses YouTube API Services. Google’s handling of data is described in the Google Privacy Policy. YouTube use is governed by the YouTube Terms of Service. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Questions and changes

Send privacy questions or complaints privately to ezerod77ia@gmail.com. Do not submit private account data in public GitHub issues. Changes to this policy will appear here with an updated date.
